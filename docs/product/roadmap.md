# AI Recorder 产品路线图

## 产品定位

AI Recorder 是面向 Windows 本机使用的录音整理工作台。核心价值是：本地保存音频和转写数据，本机完成语音转写，通过可配置云端 LLM 生成摘要、纪要、待办和规整文本。

## 当前版本线

| 版本 | 目标 | 状态 |
| --- | --- | --- |
| 0.x / MVP | 跑通上传、转写、摘要、导出、目录监控和设置页。 | 已具备基础能力 |
| 3.0 | 从可跑 MVP 升级为可日常依赖：任务可靠、可播放可校对、可搜索可批量管理。 | 主线能力已实现，待真实音频验收 |
| 3.1 | 实时体验和增强模型能力：WebSocket/SSE、说话人分离实验、URL 路由。 | 候选 |
| 3.2 | UI 技术栈和工程体系升级：设计系统、迁移工具、数据库迁移规范。 | 候选 |

## 3.0 主线

3.0 不追求一次性堆满所有能力，优先解决使用中最容易打断信任的问题：

1. 任务不能丢：重启、失败、误点、网络波动都要可见、可恢复。
2. 内容能校对：用户可以边听边看时间轴，并修正 ASR 错误。
3. 资料能管理：录音多了以后能搜索、打标签、批量处理。
4. 输出能交付：常见工作流需要的导出格式逐步补齐。

## 暂缓方向

| 方向 | 暂缓原因 | 计划 |
| --- | --- | --- |
| WebSocket/SSE | 轮询目前可用，任务状态持久化更优先。 | 3.1 |
| Tailwind/shadcn | UI 栈迁移会扩大改动面。 | 3.2 |
| 完整路由系统 | 有体验价值，但低于播放和校对。 | 3.1 |
| Alembic | 当前 SQLite 手写迁移仍可控。 | 3.1/3.2 |
| 默认说话人分离 | CPU 环境成本高。 | 3.1 实验开关 |
