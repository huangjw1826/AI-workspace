# AI Recorder 3.0

3.0 的目标是把 AI Recorder 从“核心链路可用”推进到“可以放心日常使用”。本版本优先级按实际使用阻塞排序，而不是按技术新鲜度排序。

## 版本范围

### 必做

- 任务恢复、重试、取消、并发限制。
- ffmpeg 和 LLM 调用超时。
- 音频播放和转写时间轴联动。
- 转写片段编辑保存。
- 内容搜索、标签、批量操作。
- 结构化日志和最小测试集。

### 暂不做

- 不切换 Tailwind / shadcn。
- 不拆 Celery / Redis。
- 不默认开启说话人分离。
- 不做账号系统。
- 不做全链路离线 LLM。

## 当前状态

截至 2026-05-23，3.0 主线能力已完成代码落地和机器验证。剩余工作主要是用真实音频跑一遍人工验收，以及继续打磨搜索命中位置、标签筛选等体验细节。

## 实施原则

1. 每次只做一个可验证切片。
2. 不把纯重构和功能行为混在一起。
3. 每个阶段完成后同步 README、CHANGELOG 和本目录验收清单。
4. 涉及数据模型、任务系统或部署方式的决策，补充 ADR。
