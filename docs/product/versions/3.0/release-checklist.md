# AI Recorder 3.0 发布验收清单

## Phase 0：任务可靠性

- [x] 后端启动后能处理遗留 `queued` / `running` 任务，不出现永久卡住状态。
- [x] ASR 并发数遵守 `ASR_MAX_CONCURRENCY`。
- [x] 同一录音不会重复提交同类运行中任务。
- [x] ffmpeg 超时会进入可见错误状态。
- [x] LLM 网络类失败会自动重试，并记录最终错误。
- [x] 用户可以取消尚未完成的任务。

## Phase 1：播放和校对

- [x] 详情页可以播放已入库音频。
- [x] 播放接口支持大文件，不一次性读入内存。
- [x] 播放接口不能读取未入库或越权路径。
- [x] 点击转写片段可跳转到对应时间。
- [x] 播放时当前片段高亮。
- [x] 转写片段可编辑、保存、刷新后保留。
- [x] 摘要和导出使用编辑后的转写文本。

## Phase 2：录音库管理

- [x] 搜索可命中文件名、转写文本和摘要内容。
- [ ] 搜索结果显示命中摘要或位置。
- [x] 详情页可编辑标签。
- [ ] 列表页可按标签筛选。
- [x] 可多选录音并批量转写。
- [x] 可对已有转写的录音批量摘要。
- [x] 批量删除有明确二次确认。

## Phase 3：输出和维护

- [x] 转写可导出 Markdown、TXT、JSON、SRT。
- [x] 转写和摘要可导出 DOCX。
- [x] 后端日志写入 `logs/` 并支持轮转；日志不可写时不阻断启动。
- [x] 健康检查展示最近错误摘要。
- [x] 后端关键链路有最小测试覆盖。
- [x] 前端构建通过。
- [x] 根目录 `README.md` 已同步 3.0 能力说明。
- [x] `CHANGELOG.md` 已记录 3.0 变更。

## 验证备注

- 机器验证已覆盖任务恢复、取消、音频 Range 播放、转写编辑、搜索、标签和导出核心逻辑。
- HTTP 冒烟验证使用临时数据目录启动后端，避免触碰当前只读的 `data/app.db`。
- 浏览器自动化在当前机器被 `AppData` 权限限制拦截，因此本轮未完成 Playwright 截图级视觉验证。
