# AI Recorder 3.0 完成摘要

## 已落地能力

- 任务可靠性：启动恢复、活动任务复用、取消任务、ASR 并发限制、ffmpeg 超时、LLM 超时和重试。
- 播放校对：后端音频 Range 流式播放、前端音频播放器、点击转写片段跳转、当前片段高亮。
- 转写编辑：片段级编辑保存，保存后同步数据库和转写 JSON 文件，后续摘要与导出读取编辑后的文本。
- 录音库管理：内容搜索覆盖文件名、标签、转写文本和摘要内容；详情页可维护标签；列表支持多选。
- 批量处理：批量转写、批量摘要、批量删除，并保留删除确认。
- 导出：转写支持 Markdown、TXT、JSON、SRT、DOCX；摘要支持 Markdown、TXT、DOCX。
- 运维：后端运行日志轮转，健康检查展示日志目录和最近错误，日志不可写时不阻断应用启动。

## 暂未收束到本轮的体验细节

- 搜索结果还没有显示“命中片段/命中位置”。
- 标签已经可编辑，列表页尚未提供独立的标签筛选控件。
- 浏览器截图级视觉验收受当前 Windows 权限限制影响，本轮只完成构建和 HTTP 冒烟验证。

## 验证边界

- 已验证：后端单元测试、后端编译、前端生产构建、临时数据目录下的 `/health` 与 `/api/recordings` HTTP 冒烟。
- 待人工验证：真实音频上传、转写、播放、片段编辑、摘要、导出全流程。
