# 产品规划

这里保存 AI Recorder 的产品路线、版本规划和发布验收材料。它和根目录 `README.md` 的职责不同：

- 根目录 `README.md` 面向使用者，说明如何安装、启动、使用和排错。
- `docs/product/` 面向规划和实施，说明每个版本为什么做、做什么、不做什么、如何验收。

## 目录结构

| 路径 | 用途 |
| --- | --- |
| `roadmap.md` | 跨版本路线图和优先级。 |
| `versions/` | 每个产品版本的范围、计划和验收资料。 |
| `versions/3.0/` | 3.0 迭代实施资料。 |
| `backlog/` | 暂未进入版本范围的候选需求。 |

## 版本节奏

3.0 采用小步交付：

1. 可靠性地基：任务恢复、重试、取消、并发限制。
2. 播放和校对：音频播放、时间轴联动、转写编辑。
3. 资料管理：全文搜索、标签、批量操作。
4. 输出和维护：导出扩展、日志、测试、文档同步。

每个阶段完成后都要更新对应版本目录下的验收清单。
