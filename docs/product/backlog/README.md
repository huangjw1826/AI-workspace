# 产品待办池

这里记录暂未进入当前版本范围，但值得保留的产品想法。进入具体版本前，需要先移动到对应 `docs/product/versions/<version>/` 的计划中。

## 候选需求

| 需求 | 建议版本 | 说明 |
| --- | --- | --- |
| WebSocket/SSE 实时任务推送 | 3.1 | 在任务可靠性完成后替代轮询。 |
| 说话人分离实验开关 | 3.1 | 先作为可选功能，不默认启用。 |
| URL 路由和录音详情深链 | 3.1 | 支持刷新后保留页面和直接打开录音详情。 |
| Tailwind / shadcn 迁移 | 3.2 | 需要独立 UI 重构窗口。 |
| Alembic 或 schema version 迁移体系 | 3.1/3.2 | 数据模型频繁变化后再升级。 |
| 暗色模式 | 3.2 | 当前 CSS 变量可支撑，但不影响核心链路。 |
| i18n 多语言 | 后续 | 当前中文用户优先。 |

## 进入版本的条件

1. 能明确描述用户场景。
2. 有可验证的验收标准。
3. 不破坏当前版本的主要目标。
4. 实施前确认依赖关系和风险。
